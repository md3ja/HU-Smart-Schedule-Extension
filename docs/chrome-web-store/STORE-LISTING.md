### Detailed Description (Plain text formatted for Chrome Web Store)

```text
HU Smart Schedule helps Hashemite University students explore published course sections and build conflict-free timetable options before registration.

Planning a university schedule can be challenging when course sections overlap. HU Smart Schedule simplifies registration preparation by searching university schedule data, detecting timetable conflicts, and generating clean schedule combinations tailored to your preferences.

✨ MAIN FEATURES

• 🔎 Smart & Hybrid Search — Matches course names and numbers locally against a bundled 3,203-course catalog with Arabic normalization and simultaneously queries live university listings so offered courses are always reachable with clear availability indicators. Includes independent identity resolution and graceful continuation for unoffered courses.
• ☕ Campus Break Filtering — Interactive timetable break filtering for Sunday/Tuesday/Thursday and Monday/Wednesday schedules with AND/OR selection evaluated entirely in-memory.
• 📚 Published Course Sections — Retrieve announced sections, instructors, lecture days, times, and classroom venues directly from Hashemite University's public schedule pages.
• ⚠️ Automatic Conflict Detection — Instantly identifies overlapping class times across candidate sections.
• 🧩 Schedule Generation — Generates timetable proposals without time conflicts.
• ⭐ Ranking Preferences — Sort generated proposals by fewer campus days, less Break between lectures, later starts, or earlier finishes.
• 📅 Weekly Timetable Calendar — Visual Sunday-to-Thursday calendar view with color-coded course blocks.
• ⏳ Break Calculation — Calculates Break duration between consecutive in-person lectures on the same campus day.
• 🌐 Online Lecture Compatibility — Accounts for online and blended course sections in timetable conflict checks.
• 🖥️ Full-Page Planner Mode — Expand from the toolbar popup into a full-page tab for a comfortable desktop planning experience.
• 📋 Copy Schedule Data — Copy clean section details, timings, and course numbers with one click for easy reference during registration.
• 📄 Clean A4 PDF / Print Export — Generate an organized A4 report ready to save as PDF or print using Chrome's print dialog.

🚀 HOW IT WORKS

1. Add your courses: Enter course names or course numbers.
2. Choose your semester: Select the academic year and semester.
3. Set your preferences: Filter by campus start/end times and preferred sorting.
4. Generate your schedule: Review conflict-free proposals on the weekly calendar.

🔒 PRIVACY & ARCHITECTURE

• No student portal login or password required. The extension does not request or access student account credentials.
• Course searches are sent directly to publicly available Hashemite University course schedule pages.
• Core schedule processing runs locally inside the extension.
• Conflict detection, schedule generation, ranking, Break calculation, and calendar rendering run locally.
• The developer does not operate an intermediary backend server and does not collect, receive, or store your searches.

### 🔒 Privacy & Course Searches

Smart Search matching runs locally. Live semester sections are fetched directly from hu.edu.jo using the selected course number, academic year, and semester; unresolved Arabic name searches may use HU’s name-search service. No intermediary backend or analytics is used.

HU Smart Schedule does not operate an intermediary backend server. The developer does not receive or store your searches.

Conflict detection, schedule generation, ranking, Break calculation, and calendar rendering run locally inside the extension.

⚠️ IMPORTANT NOTE

Course and section information is based on data currently published by Hashemite University and may change. Always confirm final section availability in the official registration system before registering.

ℹ️ DISCLAIMER

HU Smart Schedule is an independent project. It is not affiliated with, endorsed by, officially connected to, or approved by Hashemite University.
```
