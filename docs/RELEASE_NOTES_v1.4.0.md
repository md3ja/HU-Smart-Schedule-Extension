# HU Smart Schedule v1.4.0

## 🇬🇧 What's New in v1.4.0

HU Smart Schedule v1.4.0 introduces a refreshed dark interface, clearer schedule views, smarter search behavior, improved course management, dynamic Break filtering, and cleaner printable reports.

### ✨ Highlights

- 🌙 **Refreshed Dark Theme:** A new dark visual system with clearer contrast and improved readability across the extension.
- 🪟 **Improved Popup Layout:** Better use of the available popup space with a more stable and readable layout.
- 📅 **Clearer 5-Day Weekly Calendar:** Sunday–Thursday columns, time axis, Break indicators, off-days, and remote-course badges are easier to review at a glance.
- 🔎 **Search V2 Improvements:** Expanded support for course aliases and common student shorthand.
- 🎯 **Course Disambiguation:** When a search matches multiple subjects, you can select the intended course directly.
- 💾 **Persistent Course Draft:** Entered courses and relevant preferences are restored locally when returning to the extension.
- ➕ **Improved Course Management:** Add or remove courses during an active planning session without restarting the workflow.
- ☕ **Dynamic Break Filtering:** Choose preferred Break windows and instantly filter matching schedule proposals using the available matching modes.
- 📂 **Sections Panel Improvements:** “كل الشعب والتواقيت” opens by default and preserves the user's expand/collapse state during updates.
- ⚠️ **Clearer Conflict Review:** Improved presentation of overlapping sections and their conflicting times.
- 🖨️ **Printable Schedule Reports:** Clean white, low-ink A4 reports with schedule summaries, weekly timetables, and structured course details.
- ♿ **Accessibility Improvements:** Improved semantic controls and keyboard-friendly interaction in key expandable sections.
- 🌐 **More Reliable HU Data Requests:** Course searches use Hashemite University's canonical HTTPS endpoints for more reliable public section retrieval.

### 🛠️ Fixes

- Reduced layout shifting while moving between sections and results.
- Improved weekly-calendar sizing so all five weekdays fit cleanly without unnecessary horizontal scrolling.
- Improved course-search reliability by using the correct HU HTTPS endpoints.
- Preserved section expand/collapse state when schedules are recalculated or courses are removed.
- Improved handling of fetched public HTML to reduce unnecessary remote-resource warnings.

### 📦 Installation

1. Download **`HU-Smart-Schedule-v1.4.0.zip`** from the Assets section below.
2. Extract the ZIP file.
3. Open `chrome://extensions` in Google Chrome.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted extension folder.
7. Open HU Smart Schedule from the Chrome extensions toolbar.

> HU Smart Schedule is an unofficial student tool and is not affiliated with or endorsed by Hashemite University.

## 🇯🇴 الجديد في الإصدار 1.4.0

يقدم HU Smart Schedule v1.4.0 واجهة داكنة محدثة، وعرضاً أوضح للجداول، وتحسينات على البحث الذكي وإدارة المواد، بالإضافة إلى فلترة Break التفاعلية وتقارير طباعة أكثر ترتيباً.

### ✨ أبرز التحديثات

- 🌙 **ثيم داكن محدث:** نظام بصري داكن جديد بتباين أوضح وقراءة أسهل في مختلف أجزاء الإضافة.
- 🪟 **تحسين تخطيط نافذة الإضافة:** استغلال أفضل لمساحة النافذة مع تخطيط أكثر ثباتاً ووضوحاً.
- 📅 **تقويم أسبوعي خماسي أوضح:** عرض أسهل لأيام الأحد إلى الخميس ومحور الوقت والاستراحات وأيام العطلة والمحاضرات عن بُعد.
- 🔎 **تحسينات Search V2:** دعم أوسع لاختصارات وأسماء المواد الشائعة بين الطلبة.
- 🎯 **تحديد المادة المقصودة:** عند مطابقة البحث لأكثر من مادة يمكنك اختيار المادة المطلوبة مباشرة.
- 💾 **حفظ تلقائي لمسودة المواد:** استعادة المواد المدخلة والتفضيلات ذات الصلة محلياً عند العودة إلى الإضافة.
- ➕ **تحسين إدارة المواد:** إضافة أو حذف المواد أثناء جلسة التخطيط دون الحاجة للبدء من جديد.
- ☕ **فلترة Break تفاعلية:** اختيار فترات الاستراحة المفضلة وفلترة الجداول المطابقة مباشرة باستخدام أوضاع المطابقة المتاحة.
- 📂 **تحسين لوحة الشعب:** تفتح لوحة “كل الشعب والتواقيت” افتراضياً وتحافظ على حالة الطي والتوسيع أثناء التحديثات.
- ⚠️ **مراجعة أوضح للتعارضات:** عرض أوضح للشعب المتعارضة والأوقات المتداخلة بينها.
- 🖨️ **تقارير طباعة محسنة:** تقارير بيضاء وموفرة للحبر بحجم A4 تتضمن ملخص الجدول والتقويم الأسبوعي وتفاصيل المواد والشعب.
- ♿ **تحسينات إمكانية الوصول:** تحسين عناصر التحكم والتنقل بلوحة المفاتيح في الأقسام القابلة للطي والتوسيع.
- 🌐 **اتصال أكثر موثوقية ببيانات الجامعة:** استخدام روابط HTTPS الرسمية لجريدة المواد العامة لتحسين موثوقية جلب الشعب.

### 🛠️ الإصلاحات

- تقليل اهتزاز وتغير التخطيط أثناء التنقل بين الأقسام والنتائج.
- تحسين أبعاد التقويم لعرض أيام الأسبوع الخمسة دون تمرير عرضي غير ضروري.
- تحسين موثوقية البحث باستخدام روابط HTTPS الصحيحة للجامعة.
- الحفاظ على حالة فتح أو طي لوحة الشعب عند إعادة حساب الجداول أو حذف مادة.
- تحسين معالجة محتوى HTML المجلوب من موقع الجامعة لتقليل تحذيرات الموارد الخارجية غير الضرورية.
